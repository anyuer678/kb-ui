# M4 create-kb 脚手架 CLI + 模板实施计划

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 提供 `pnpm create kb` 命令，交互式（或参数指定）生成一个预装 @kb/ui 的 Vue 3 + Vite + TS 新项目；模板版本与 @kb/ui 配套。

**Architecture:** `packages/create-kb` 是一个 Node CLI（commander 解析参数 + prompts 交互 + tsup 打包单文件 bin）。模板以静态目录内嵌在包内（`templates/base` 最小可用、`templates/starter` 带完整示例页），生成时复制 → 替换 `{{projectName}}`/`{{packageName}}`/`{{kbVersion}}` 占位符 → 可选 git init → 打印后续命令。

**Tech Stack:** Node ≥ 20、commander、prompts、tsup（build）、@kb/ui（workspace 引用取版本号）。

## Global Constraints

- 命令形态：`pnpm create kb <name>`（非交互）或 `pnpm create kb`（交互）；`--template base|starter`、`--no-git` 可选。
- 项目名校验：npm 包名规则（小写、无空格、合法字符）；目标目录已存在且非空时询问覆盖。
- 模板占位符：`{{projectName}}`、`{{packageName}}`（npm 安全包名）、`{{kbVersion}}`（读取 create-kb 依赖的 @kb/ui 版本）。
- 模板 base 包含：Vite + Vue 3 + TS + @kb/ui（全量引入 + 样式）+ 暗色主题切换按钮 + lint 配置 + README；starter = base + 完整示例页（表格/表单/消息）。
- 生成后打印：安装命令、启动命令。
- 每任务提交（Conventional Commits）。
