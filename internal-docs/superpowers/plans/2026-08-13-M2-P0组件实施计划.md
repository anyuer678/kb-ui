# M2 P0 组件实施计划（12 个组件）

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 Button/Icon 已确立的组件范式（`packages/ui/src/components/<Name>/` 下 4 文件 + TDD），完成剩余 12 个 P0 组件，达到设计文档 §4.2 的 P0 清单（共 14 个，Button/Icon 已在 M0-M1 完成）。

**Architecture:** 每个组件独立目录（`<Name>.vue` / `style.css` / `index.ts` / `__tests__/<Name>.spec.ts`）；完成后在 `src/index.ts` 追加 `export *` 并加入 `components` 数组；样式由 build-styles.mjs 自动输出到 `dist/styles/<Name>.css`。

**Tech Stack:** 同 M0-M1（Vue 3.5 + TS + Vitest + @vue/test-utils + 原生 CSS token）。

## Global Constraints

（与 M0-M1 计划一致，逐字生效；范式见 `docs/superpowers/plans/2026-08-13-M0-M1-工程底座与组件库骨架.md` Task 5/6）

- `defineOptions({ name: 'Kb<Name>' })`；props `withDefaults(defineProps<Props>())` + `export interface <Name>Props`；事件 `defineEmits`；v-model 用 `modelValue`/`update:modelValue`。
- 样式只引用 `--kb-*` token；class 前缀 `kb-`；通过 stylelint（`kb-` 语义化命名校验）。
- 每个组件 ≥ 4 个测试用例（渲染 / props / 事件 / v-model）。
- 测试命令 `pnpm -F @kb/ui test`；lint `pnpm -F @kb/ui lint`；完成后全量 `pnpm lint && pnpm typecheck && pnpm test && pnpm build`。
- 提交信息 Conventional Commits（`feat(ui): add Kb<Name> component`）。

**执行节奏**：按批次 A（基础）→ B（表单）→ C（反馈）→ D（数据展示）推进，每完成 1 个组件立即提交；每批次完成跑一次全量验证。
