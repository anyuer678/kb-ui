# M0-M1 工程底座与组件库骨架实施计划

> **For agentic workers:** Execute this plan task-by-task, dispatching a fresh subagent per task via the task tool (recommended) with review between tasks, or executing inline in this session. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建好 pnpm monorepo 工程底座，并用 Button/Icon 两个组件打样，跑通"写组件 → 打包 → 类型 → 测试"完整闭环，为后续 12 个 P0 组件确立标准范式。

**Architecture:** 根目录为 pnpm workspace（packages/ui 组件库 + packages/config 共享配置）；@kb/ui 用 Vite lib mode 输出 ESM+CJS+d.ts，样式用原生 CSS + CSS 变量 token；测试用 Vitest + @vue/test-utils。

**Tech Stack:** pnpm ≥ 9、Node ≥ 20（本机 24.15.0）、Vue 3.5、Vite 7、vite-plugin-dts 5、TypeScript 5.9、Vitest 4、@vue/test-utils 2.4、ESLint 9（flat config）、Prettier、stylelint 16

## Global Constraints

（来自设计文档 docs/superpowers/specs/2026-08-13-component-library-and-scaffold-design.md，逐字生效）

- 包名占位 `@kb/ui`、`@kb/config`；组件前缀 `Kb`、class 前缀 `kb-`（命名待用户最终确认，批准后全局可替换）。
- 组件全部 `<script setup lang="ts">` + `defineOptions({ name: 'KbButton' })`；props 用 `withDefaults(defineProps<Props>())`，事件用 `defineEmits`，v-model 用 `modelValue` / `update:modelValue`。
- 样式只用原生 CSS + CSS 变量，禁止硬编码色值/圆角/间距；token 前缀 `--kb-`；class 语义化 `kb-<component>-<element>`。
- 依赖极简：`vue` 是唯一 peerDependency（`^3.4.0`）；运行时零第三方依赖。
- 产物：ESM（`dist/index.js`）+ CJS（`dist/index.cjs`）+ d.ts + 按组件样式 `dist/styles/<Name>.css`；`sideEffects: ["**/*.css"]`。
- 不使用任何 CSS-in-JS / CSS 预处理器。
- 提交信息用 Conventional Commits。

- [ ] **Step 3: 实现 Button.vue**

```vue
<script setup lang="ts">
import { computed } from 'vue'

defineOptions({ name: 'KbButton' })

const props = withDefaults(
  defineProps<{
    type?: 'default' | 'primary' | 'success' | 'warning' | 'danger' | 'info'
    size?: 'small' | 'medium' | 'large'
    disabled?: boolean
    round?: boolean
    plain?: boolean
    nativeType?: 'button' | 'submit' | 'reset'
  }>(),
  {
    type: 'default',
    size: 'medium',
    disabled: false,
    round: false,
    plain: false,
    nativeType: 'button',
  },
)

defineEmits<{ click: [event: MouseEvent] }>()

const classes = computed(() => [
  'kb-button',
  `kb-button--${props.type}`,
  `kb-button--${props.size}`,
  {
    'kb-button--disabled': props.disabled,
    'kb-button--round': props.round,
    'kb-button--plain': props.plain,
  },
])
</script>

<template>
  <button
    :type="nativeType"
    :class="classes"
    :disabled="disabled"
    @click="$emit('click', $event)"
  >
    <slot />
  </button>
</template>
```
