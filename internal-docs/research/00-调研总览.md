## 综合启示（对设计的净结论）

1. **技术选型确认**：Vue 3 + TS + Vite lib mode + vite-plugin-dts + Vitest + pnpm workspace + changesets + tsup(CLI) + Vitepress——与主流/社区共识一致，设计文档无需大改。
2. **产物**：ESM（按组件目录，利于按需）+ CJS 双格式 + d.ts 是标配；`exports` 精确映射 + `sideEffects` 声明 CSS。**可补充 UMD 产物**（CDN 场景，Vite lib mode 顺手）。
3. **Design System 前置**：token 体系（CSS 变量）是一等公民，先定设计语言再写组件，避免"先实现后补设计"的返工（Varlet 的教训）。
4. **API 克制**：首版 props 收敛、命名规范统一（value/onChange 风格）、少开放接口。
5. **依赖克制**：主流大库依赖多，精品库（Naive/Varlet）倾向自研小工具；首版只引入必要依赖。
6. **工程化拉满**：CI 自动 lint/test/build、changesets 版本管理、GitHub Actions + npm OIDC provenance 发布、文档站 Vercel/Gitee Pages 托管。
7. **发布纪律**：semver + alpha/beta/rc 先行版本；`pnpm create kb` 与 `@kb/ui` 版本配套（生成时写入当前版本）。
8. **组件库生命周期工具化是共识**（Arco scripts / Varlet-cli / easyest）：create-kb 可扩展 `kb add <component>` 与发布脚本（二期）。
9. **按需消费**由 unplugin-vue-components 统一解决（545万/月，全构建器支持）；组件库只保证 ESM + 按组件样式。
10. **依赖拆包**（@varlet/use、@varlet/icons、@varlet/shared）：二期拆 @kb/shared、@kb/icons。
