# 构建 / 发布 / 文档工具链调研

> 数据采集日期：2026-08-13 · 来源：npm registry（下载量 = 2026-07-11 ~ 08-09 月下载量）

## 1. 工具对比

| 工具 | 最新版 | 月下载量 | 定位 |
|---|---|---|---|
| tsup | 8.5.1 | 30,605,176 | 通用 TS 库打包（esbuild 内核） |
| vite-plugin-dts | 5.0.3 | 15,651,934 | Vite lib mode 下生成 d.ts |
| Vitepress | 1.6.4 | 2,989,725 | Vue 文档站 |
| unbuild | 3.6.1 | 973,519 | Rollup 封装的库构建（较 niche） |

## 2. 结论

- **tsup 是 TS 库打包的事实标准**（月下载 3000 万+），零配置出 ESM+CJS+d.ts；用 esbuild 打包、rollup-plugin-dts 出类型。
- **vite-plugin-dts 5.x 是 Vite 库模式的首选 d.ts 方案**（1565 万/月），与我们的 `vite build` lib mode 无缝集成；注意 5.x 为当前 latest（4.x → 5.x 有配置变化，实施时按 5.x 文档写）。
- **Vitepress** 是 Vue 生态文档站标准（299 万/月），1.6.4 稳定、2.0 尚在 alpha——用 1.x 稳定版。
- **unbuild** 下载量小得多，Vue 组件库场景（含 .vue SFC 处理）用 tsup/vite lib mode 更顺手，**不采用**。
- 补充（来自 create-vite/create-vue 的工程实践）：**tsdown / rolldown** 是新一代 rolldown 构建链（Vite 官方团队方向），create-vue 已切到 rolldown 构建自身；我们 CLI 用 tsup 即可，后续可观察 rolldown 生态成熟度。

## 3. 对我们设计文档的确认

| 设计文档原方案 | 调研结果 | 状态 |
|---|---|---|
| Vite lib mode 打包组件库 | 主流做法（Element/Naive 虽用 tsc+rollup，但 Vite lib mode 对 SFC 支持好、社区验证充分） | ✅ 维持 |
| vite-plugin-dts 生成类型 | 行业标准，1565 万/月 | ✅ 维持（按 5.x 配置） |
| Vitepress 文档站 | 标准方案 | ✅ 维持（1.6.x 稳定版） |
| tsup 打包 create-kb CLI | 事实标准 | ✅ 维持 |
| unbuild | 不必要 | ✅ 排除 |
