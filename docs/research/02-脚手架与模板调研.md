## 2. create-vite（9.1.2）

- **定位**：Vite 官方脚手架，`npm create vite@latest`；Vue/React/Svelte/Solid/Lit/vanilla 多框架 + 各框架 TS 变体模板。
- **实现**：
  - 参数解析 `mri`，交互 `@clack/prompts`（现代终端 UI，spinner/多选体验好）；
  - 构建自身 CLI 用 **tsdown**（rolldown 封装，极快）；
  - 模板以目录内嵌在 npm 包（unpackedSize 866KB，242 文件）。
- **Node 要求**：`^20.19.0 || >=22.12.0`（较高，与 Vite 7 时代对齐）。
- **bin**：同时暴露 `create-vite` 与缩写 `cva`。
- **特点**：提供 `--template` 显式指定模板、交互式框架选择。

## 3. create-vue（3.23.0）

- **定位**：Vue 官方脚手架，`npm create vue@latest`（⚠️ README 强调 `@latest` 不可省略，否则 npm 可能命中缓存旧版）。
- **交互特性**（feature flags 可跳过交互）：
  - `--typescript`、`--router`、`--pinia`、`--eslint`、`--vitest`、`--cypress`/`--playwright`、`--bare`（最小骨架）等；
  - PowerShell 用户需引号包裹双横线：`npm create vue@latest '--' --help`。
- **实现**：
  - 交互 `@clack/prompts`；构建自身用 **rolldown**（`rolldown.config.ts`）+ vite-plus；
  - 模板文件内嵌（unpackedSize 228KB，142 文件）；
  - 测试用 vitest + zx 脚本，做生成快照测试（snapshot 对比生成的工程）。
- **Node 要求**：`^22.18.0 || >=24.12.0`（当前最高）。
- **设计哲学**（README 明示）：create-vue 本身**只是一个脚手架工具**——按所选特性生成预配置工程，其余交给 Vite 生态（对比旧 Vue CLI 的 webpack 全家桶）；"generated project 可直接利用 Vite 插件生态（Rollup 兼容）"。
- **质量实践**：自带 snapshot 测试 + release 脚本 + provenance 发布（`publishConfig.provenance: true`）。

## 4. 对自研脚手架（create-kb）的借鉴

| 维度 | create-vite / create-vue 做法 | create-kb 采纳 |
|---|---|---|
| 参数解析 | mri / commander | **commander**（成熟、帮助文档自动生成） |
| 交互 | @clack/prompts | **prompts** 或 @clack/prompts（二选一，倾向 @clack/prompts 体验现代） |
| CLI 构建 | tsdown / rolldown | **tsup**（生态最广、配置零成本） |
| 模板存放 | 目录内嵌 npm 包 + 生成时替换 | 同（templates/ 静态目录 + 占位符替换） |
| 生成校验 | 目录检查、覆盖询问 | 同 + npm 包名规则校验 |
| 测试 | 生成快照测试（zx + vitest） | 加入 M5 发布链路验证（端到端跑一次生成） |
| 版本配套 | 模板内依赖随脚手架版本走 | 生成时写入当前 @kb/ui 版本（设计文档 §6.2 已定） |
| 发布 | provenance + GitHub Actions | 同（OIDC provenance） |
| Node 要求 | 20+/22+ | **Node >= 20**（用户环境 Node 24，宽松兼容） |

**额外发现：** create-vue 用 `--bare` 提供极简骨架，与我们的 `base`（最小可用）模板思路一致；starter 模板可参考"特性组合"式交互（ts？示例页？lint？），默认全开、参数可跳。
